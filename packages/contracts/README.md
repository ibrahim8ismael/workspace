# Public contracts

Browser-safe runtime schemas and DTOs only. Current exports: API liveness response schema, strict auth/company request schemas, and safe account/workspace TypeScript DTOs from `src/http/auth.ts`. Strict existing-API response projections/wrappers are now exported from `src/http/responses.ts`; safe HTTP error codes/envelopes are in `src/errors.ts`. These schemas do not automatically install production response validation; existing HTTP responses are checked in integration tests. Office admission/events and protocol versions remain the next CP01 contract slice. Run `pnpm test:contracts` for projection/leak checks. Do not export session digests, credential models, server policy or internal media-control messages.
